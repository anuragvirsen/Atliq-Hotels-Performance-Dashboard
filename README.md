# 🏨 AtliQ Hotels Performance Dashboard | Power BI

## 📌 Project Overview
Developed an interactive **Hotel Performance Dashboard** in **Power BI** to analyze key hospitality KPIs, including **Revenue, Occupancy %, ADR, RevPAR, and Cancellation Rate**. Leveraged **Power Query, DAX, and data modeling** to create dynamic visualizations, city-wise analysis, and property-level insights for effective business decision-making.
